# VISION

建立一套可持續演化的電商系統。

系統不以一次性生成完成為目標，而是在持續的刺激、觀察、決策、執行與驗證中逐步成長。

由 DNA 封裝決策方法，決定當前最值得處理的問題、應採取的方向、需要調用的能力，以及何時繼續演化、修正、回退或穩定。

由 Skills 封裝執行能力，負責分析、設計、實作、測試、驗證、文件化與其他具體工作。

每一次改變都應建立在既有成果與證據之上，使系統能反覆修正自身，而不是每次重新生成。

當資訊不足、需求改變、發現缺陷或收到新的刺激時，系統應能自主判斷影響、形成下一步行動並驗證結果，盡可能減少人類持續下達微觀指令的需要。

最終目標不是生成一個固定形態的電商系統，而是讓它能根據環境與持續輸入，自主成長為當下應有的樣子。

**Drop it in. Let it grow. 🌱**
